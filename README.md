# 肺機能 LMS リファレンス 第5版

## Excel読込・端末内計算版（試作）

一般社団法人日本呼吸器学会が公開している計算用Excelを、利用者自身が読み込んで使用する教育用Webアプリです。

- 試作アプリ：<https://pulmonary-lms-local-excel.kaibo-chan.chatgpt.site/>
- 日本呼吸器学会の配布ページ：<https://www.jrs.or.jp/activities/guidelines/statement/20220428151435.html>

## 公開状況

本アプリは試作版です。現在、日本呼吸器学会に対する使用許諾手続を進めています。

学会の計算用Excel、予測式、係数表および年齢別splineデータは、このリポジトリには収録していません。利用者が日本呼吸器学会の配布ページから公式Excelを取得し、アプリ上で選択する方式です。

許諾条件等に応じて、公開内容を変更または停止する場合があります。

## 主な機能

- 性別・年齢・身長から、FEV₁、FVC、VC、FEV₁/FVCの予測値と正常下限値（LLN）を表示
- 実測値がある場合にZ-scoreと下側百分位を表示
- 各指標の標準正規分布グラフ
- FEV₁/FVCと%VCを用いた換気パターンの参考表示
- FEV₁とFVCからFEV₁/FVCを自動計算（手動入力・上書きにも対応）
- VCと予測VCから%VCを自動計算（手動入力・上書きにも対応）
- iPhoneのホーム画面追加とオフライン起動に対応

## 使い方

1. 日本呼吸器学会の配布ページから、計算用Excelをダウンロードします。
2. 試作アプリを開き、「Excelを選択」を押します。
3. ダウンロードしたExcelを選択します。
4. 性別・年齢・身長、必要に応じて実測値を入力します。

## プライバシー

Excelファイルと入力値はブラウザ内で処理し、計算のために外部サーバーへ送信しません。

選択したExcelは、同じ端末で次回も利用できるようブラウザの保存領域に保存されます。年齢・身長・実測値は保存しません。保存したExcelは、アプリの「端末から削除」で消去できます。

## 計算方法

- 学会の係数表・予測式を、アプリのソースには収録していません。
- Microsoft Excelを起動する方式ではありません。
- 読み込んだブック内のセル参照と数式をJavaScriptで評価します。
- 公式ブックで使用されている `IF`、`LOOKUP`、`EXP`、`LN` に対応しています。
- 必要なシート、出力セルまたは数式を確認できないブックは受け付けません。
- `#NUM!`、`#N/A`、`#VALUE!`、`#DIV/0!` などに相当する状態は、計算不可として表示します。

## 動作確認

第4版の計算結果を基準として、男女・17～93歳の代表例について、FEV₁、FVC、VC、FEV₁/FVCの予測値・LLN・Z-scoreを照合しました。96項目の不一致は0で、最大絶対差は `4.44 × 10⁻¹⁶` でした。

## ローカルでの起動

`dist` フォルダを静的Webサーバーで配信してください。

例：

```sh
python3 -m http.server 8000 --directory dist
```

その後、ブラウザで `http://localhost:8000/` を開きます。

ファイルを直接開いても基本画面は表示できますが、ホーム画面への追加、オフライン動作、端末内保存の確認には、HTTPSまたはlocalhostでの配信が必要です。
