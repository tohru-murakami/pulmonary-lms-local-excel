# 公式Excelとの照合記録（2026年11月14日）

## 目的

日本呼吸器学会が配布する計算用ExcelをMicrosoft Excelで実行した結果と、本Webアプリが同じExcelを読み込んで計算した結果を照合した。

## 対象

- アプリ：肺機能 LMS リファレンス Excel読込・端末内計算版 v1.0（261112）
- Excelファイル名：`975f2e115ae86c3000bd097967e9995e2c9b9a3f.xlsx`
- Excelファイル SHA-256：`1c4f2e6bc62309eb5331a500a838197e189f8ae12a2fcf69a9a77a31a434ef69`
- Excel実行環境：Microsoft Excel for Mac
- 照合日：2026年11月14日

Excelファイル自体は本リポジトリに収録していない。

## 判定方法

男性10例・女性10例について、同一の性別・年齢・身長・実測値を公式ExcelとWebアプリに与えた。

各例でFEV₁、FVC、VC、FEV₁/FVC、%VCについて、予測値、LLN、予測比、Z-scoreに相当する20個の数値を比較した。許容差は `1×10⁻⁹` とした。

公式Excelの全入力・全出力値は、[公式Excel出力データ](../tests/official-excel-expected-2026-11-14.json)に保存している。再実行には[専用照合ページ](../tests/verification-runner.html)を使用する。

## 結果

- 照合例数：20例
- 数値比較：400項目
- 不一致：0項目
- 全体の最大差：`4.973799150320701×10⁻¹³`
- 判定：すべて許容差 `1×10⁻⁹` 以内で一致

最大差は浮動小数点演算に伴う丸め誤差の範囲であり、画面表示値には影響しない。

## 再現方法

1. リポジトリ直下をローカルWebサーバーで配信する。
2. `tests/verification-runner.html` を開く。
3. 上記SHA-256と一致する公式Excelを選択する。
4. 「20例を照合」を押す。
5. 「20例・400項目がすべて一致しました」と表示されることを確認する。

専用照合ページはExcelと入力値をブラウザ内で処理し、外部サーバーへ送信しない。

## 限界

この照合は、記録した20例について数式評価が一致することを示す。すべての年齢・身長・実測値、入力範囲の境界、異常入力および将来更新される別のExcelファイルに対する完全な検証を意味しない。
